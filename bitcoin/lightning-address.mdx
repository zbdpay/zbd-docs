## Description

A Lightning Address is an internet identifier (akin to an email address -- `andre@zbd.gg`) that anyone can use to send you Bitcoin Lightning Network payments. It's as easy as giving out your email address.

Leverage this API to programmatically perform these types of payments.

  <img src="/img/v2/lightningaddresscom.png" alt="lightningaddress.com" />
</Frame>

As creators of the [Lightning Address open source standard](https://github.com/andrerfneves/lightning-address), we believe this API to be the single most frictionless way of using Bitcoin today.

## Common use cases

- **User-to-user payments.** No more sharing long strings like `lnbc1x0...` — just `user@provider.com`, with instant settlement. Anyone can send and receive global payments as easily as sending an email.
- **Reward payouts.** Let a player enter their Lightning Address once, then fire payouts automatically once their earnings cross a threshold. Set it and forget it.
- **Wallet transfers.** Users can move money between wallets (see the ZBD App for an example) by connecting a Lightning Address — moving value to and from ZBD becomes trivial.
- **Payroll and payouts.** A static address on the internet makes recurring payments simple: the recipient confirms their address once, and every payout lands instantly at near-zero fees.
- **Splits.** Programmable money means programmable splitting — an album sale can fire proportional payments to every band member's Lightning Address instantly, no matter which Lightning provider they use.
- **Deposits.** Give each user an address of their own; deposits from other apps or payrolls are as easy as handing out an email.
- **Payments.** To pay someone, type in their Lightning Address and the amount. That's it.

To learn more, visit [lightningaddress.com](https://lightningaddress.com).
