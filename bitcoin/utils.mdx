## Utility APIs

When integrating ZBD API for payments capabilities in your system, it's important to have utility functions ready to help you go from 0 to 1.
We've made a set of these Utility APIs available to help you integrate faster.

<CardGroup cols={2}>
  <Card title="BTC USD Exchange Rate" icon="bitcoin" color="#ff9900" href="/bitcoin/utils/btc-usd">
    Fetches the latest price for 1 Bitcoin in US dollars for price calculations.
  </Card>
  <Card title="Is Supported Region" icon="earth-americas" color="#000000" href="/bitcoin/utils/is-supported-region">
    Determines whether a user is located in a region ZBD is available in.
  </Card>
  <Card title="ZBD Production IPs" icon="wifi" color="#9563FF" href="/bitcoin/utils/ip">
    Provides up-to-date static IP addresses for ZBD servers.
  </Card>
  <Card title="Internal Transfers" icon="bolt" color="#32d615" href="/bitcoin/wallet/internal-transfer">
    Move funds from one ZBD Project to another programmatically.
  </Card>
</CardGroup>
