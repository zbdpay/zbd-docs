Download the ZBD Earn SDK for Unity below. Each release links to the `.unitypackage` to import into your project and lists what changed.

<Warning>
**Downloads require access.** The SDK is hosted in a private GitHub repository, so you need to be granted access before you can download it.

If a download link shows **"404 — Page not found"**, your GitHub account hasn't been granted access yet. Reach out to your account manager with your **GitHub username or the email on your GitHub account**, and they'll add you.
</Warning>
