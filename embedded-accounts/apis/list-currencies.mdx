---
title: "List currencies"
description: "List your virtual currencies."
api: "GET https://api.zbdpay.com/api/v1/publishers/{publisherId}/virtual-currencies"
---

## Description

Returns the virtual currencies you have defined. Soft-deleted currencies are not
included.

## Configuration

### Header Parameters

<ParamField required header="x-api-key" type="string">
  Your ZBD publisher API key. Call this from your server only.
</ParamField>

### Path Parameters

<ParamField required path="publisherId" type="string">
  Your ZBD publisher ID.
</ParamField>

### Query Parameters

<ParamField query="id" type="string">
  Filter to a single currency by its ID.
</ParamField>

<ParamField query="code" type="string">
  Filter to a single currency by its ticker, for example `GOLD`.
</ParamField>

<ParamField query="skip" type="integer">
  Number of rows to skip.
</ParamField>

<ParamField query="take" type="integer">
  Number of rows to return.
</ParamField>

<RequestExample>
```bash cURL
curl https://api.zbdpay.com/api/v1/publishers/{publisherId}/virtual-currencies \
  -H "x-api-key: YOUR_API_KEY"
```

## Errors

| Status | Reason |
|---|---|
| `401` | Missing or invalid API key |
| `403` | The API key does not belong to `publisherId` |
