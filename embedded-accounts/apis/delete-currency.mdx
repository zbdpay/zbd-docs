---
title: "Delete a currency"
description: "Soft-delete a currency."
api: "DELETE https://api.zbdpay.com/api/v1/publishers/{publisherId}/virtual-currencies/{currencyCode}"
---

## Description

Soft-deletes a virtual currency. The currency stops appearing in
[List currencies](/embedded-accounts/apis/list-currencies) and can no longer be
credited or debited, but the ledger history of transactions in that currency is
preserved.

## Configuration

### Header Parameters

<ParamField required header="x-api-key" type="string">
  Your ZBD publisher API key. Call this from your server only.
</ParamField>

### Path Parameters

<ParamField required path="publisherId" type="string">
  Your ZBD publisher ID.
</ParamField>

<ParamField required path="currencyCode" type="string">
  The currency ticker, for example `GOLD`.
</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE https://api.zbdpay.com/api/v1/publishers/{publisherId}/virtual-currencies/GOLD \
  -H "x-api-key: YOUR_API_KEY"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "success": true,
  "message": "Virtual currency deleted successfully.",
  "data": null,
  "error": null
}
```
</ResponseExample>

## Errors

| Status | Reason |
|---|---|
| `401` | Missing or invalid API key |
| `403` | The API key does not belong to `publisherId` |
| `404` | No such currency, or it has already been soft-deleted |
