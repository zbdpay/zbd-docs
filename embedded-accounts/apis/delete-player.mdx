---

## Description

Queues a player for archival. This is a request, not an immediate delete — the
account is scheduled for removal and processed asynchronously.

Use this to service a player's data-erasure request.

<Warning>
  An account that still holds funds or has a payout in progress cannot be
  archived. Pay out or zero the balance first.
</Warning>

## Configuration

### Header Parameters

<ParamField required header="x-api-key" type="string">
  Your ZBD publisher API key. Call this from your server only.
</ParamField>

### Path Parameters

<ParamField required path="publisherId" type="string">
  Your ZBD publisher ID.
</ParamField>

<ParamField required path="userId" type="string">
  The ZBD user ID returned by [Create a player](/embedded-accounts/apis/create-player).
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://api.zbdpay.com/api/v1/publishers/{publisherId}/users/{userId}/deletion-request \
  -H "x-api-key: YOUR_API_KEY"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "success": true,
  "message": "Deletion request queued successfully.",
  "data": null,
  "error": null
}
```
</ResponseExample>

<Tip>
  Verify the requester is the account holder before you call this. Archival is
  not reversible.
</Tip>

## Errors

| Status | Reason |
|---|---|
| `401` | Missing or invalid API key |
| `403` | The API key does not belong to `publisherId` |
| `404` | No such user under this publisher |
