---
title: "Get a currency"
description: "Get one currency."
api: "GET https://api.zbdpay.com/api/v1/publishers/{publisherId}/virtual-currencies/{currencyCode}"
---

## Description

Returns a single virtual currency by its ticker.

## Configuration

### Header Parameters

<ParamField required header="x-api-key" type="string">
  Your ZBD publisher API key. Call this from your server only.
</ParamField>

### Path Parameters

<ParamField required path="publisherId" type="string">
  Your ZBD publisher ID.
</ParamField>

<ParamField required path="currencyCode" type="string">
  The currency ticker, for example `GOLD`.
</ParamField>

<RequestExample>
```bash cURL
curl https://api.zbdpay.com/api/v1/publishers/{publisherId}/virtual-currencies/GOLD \
  -H "x-api-key: YOUR_API_KEY"
```
</RequestExample>

## Errors

| Status | Reason |
|---|---|
| `401` | Missing or invalid API key |
| `403` | The API key does not belong to `publisherId` |
| `404` | No such currency, or it has been soft-deleted |
