---
title: "Create a currency"
description: "Create a currency."
api: "POST https://api.zbdpay.com/api/v1/publishers/{publisherId}/virtual-currencies"
---

Create a currency. `code` `^[A-Z0-9]{2,4}$`, `name` ≤ 100, `icon_url` optional, `precision` **required** and may be 0 — omitting it is a 400, not a default

<ParamField header="x-api-key" type="string" required>
  Your ZBD API key. Call this endpoint from your server only.
</ParamField>

<ParamField path="publisherId" type="string" required>
  Your ZBD publisher ID.
</ParamField>
