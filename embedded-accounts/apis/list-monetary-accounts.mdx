title: "List monetary accounts"

api: "GET https://api.zbdpay.com/api/v2/projects/{projectId}/monetary-accounts"
---

## Description

Returns the monetary accounts held by a project, along with the cash out routing
type in force for each.

<Note>
  This route is on the **legacy developer API key** scheme (`apikey`), not the
  publisher key (`x-api-key`) used by the rest of Embedded Accounts. It is also
  the only `/api/v2/` route on this surface.
</Note>

## Configuration

### Header Parameters

<ParamField required header="apikey" type="string">
  Your ZBD project API key.
</ParamField>

### Path Parameters

<ParamField required path="projectId" type="string">
  The ZBD project ID.
</ParamField>

<RequestExample>
```bash cURL
curl https://api.zbdpay.com/api/v2/projects/{projectId}/monetary-accounts \
  -H "apikey: YOUR_API_KEY"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "success": true,
  "message": "Monetary accounts retrieved successfully.",
  "data": [
    {
      "id": "f19c7d44-2b85-4e03-9a7f-6c1d8b0e5a23",
      "currency": "USD",
      "cashoutRoutingType": "EMBEDDED_PAYOUTS"
    }
  ],
  "error": null
}
```
</ResponseExample>

## Errors

| Status | Reason |
|---|---|
| `401` | Missing or invalid API key |
| `403` | The API key is not allowed to access this project |
| `404` | No such project |
