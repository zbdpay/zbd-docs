## Description

Updates a project. This is a merge-patch: send only the fields you want to
change.

<Warning>
  An omitted field and an explicit `null` are indistinguishable here — **both
  mean unchanged**. There is no way to clear `description` by sending `null`.
</Warning>

The slug `name` is derived server-side and cannot be patched.

<Info>
  **Requires activation.** Available once ZBD switches this feature on for your
  account. Until then it returns a bare `503` — that means the feature is off,
  not that the API is down. Ask your ZBD contact to enable it.
</Info>

## Configuration

### Header Parameters

<ParamField required header="x-api-key" type="string">
  Your ZBD publisher API key. Call this from your server only.
</ParamField>

### Path Parameters

<ParamField required path="publisherId" type="string">
  Your ZBD publisher ID.
</ParamField>

<ParamField required path="projectId" type="string">
  The project ID returned when the project was created.
</ParamField>

### Body

<ParamField body="display_name" type="string">
  Human-readable name for the project, up to 256 characters.
</ParamField>

<ParamField body="description" type="string">
  Description, up to 1000 characters.
</ParamField>

<RequestExample>
```bash cURL
curl -X PATCH https://api.zbdpay.com/api/v1/publishers/{publisherId}/projects/{projectId} \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "display_name": "Fortnite Rewards (EU)"
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
```

</ResponseExample>

Note that the slug `name` does not change when `display_name` does.

## Errors

| Status | Reason |
|---|---|
| `400` | `display_name` over 256 characters, or `description` over 1000 |
| `401` | Missing or invalid API key |
| `403` | The API key does not belong to `publisherId` |
| `404` | No such project, or it has been soft-deleted |
| `503` | The Embedded Accounts feature is not switched on for your account |
