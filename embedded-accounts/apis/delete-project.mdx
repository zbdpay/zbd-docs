---
title: "Delete a project"
description: "Soft-delete a project."
api: "DELETE https://api.zbdpay.com/api/v1/publishers/{publisherId}/projects/{projectId}"
---

## Description

Soft-deletes a project. It stops appearing in
[List projects](/embedded-accounts/apis/list-projects) and can no longer be
named in an `x-project-id` header, but the ledger history of transactions
scoped to it is preserved.

<Info>
  **Requires activation.** Available once ZBD switches this feature on for your
  account. Until then it returns a bare `503` — that means the feature is off,
  not that the API is down. Ask your ZBD contact to enable it.
</Info>

## Configuration

### Header Parameters

<ParamField required header="x-api-key" type="string">
  Your ZBD publisher API key. Call this from your server only.
</ParamField>

### Path Parameters

<ParamField required path="publisherId" type="string">
  Your ZBD publisher ID.
</ParamField>

<ParamField required path="projectId" type="string">
  The project ID returned when the project was created.
</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE https://api.zbdpay.com/api/v1/publishers/{publisherId}/projects/{projectId} \
  -H "x-api-key: YOUR_API_KEY"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "success": true,
  "message": "Project deleted successfully.",
  "data": null,
  "error": null
}
```
</ResponseExample>

## Errors

| Status | Reason |
|---|---|
| `401` | Missing or invalid API key |
| `403` | The API key does not belong to `publisherId` |
| `404` | No such project, or it has already been soft-deleted |
| `503` | The Embedded Accounts feature is not switched on for your account |
