---

## Description

Mints a session token for a player so the widget can act on their behalf. The
token is a **JWT valid for four hours**, carrying the `project_id` and the
resolved principal.

<Warning>
  This does **not** create the player. Provision them first with
  [Create a player](/embedded-accounts/apis/create-player); minting a session
  for an unknown player fails.
</Warning>

Membership is checked at mint time: the player must belong to the project you
name. Mint the token on your server and hand it to the client — never ship the
publisher API key itself.

Session tokens are what the player-scoped endpoints accept. A publisher API key
cannot read a player's balance or history; only a session can.

## Configuration

### Header Parameters

<ParamField required header="x-api-key" type="string">
  Your ZBD publisher API key. Call this from your server only.
</ParamField>

### Body

<ParamField required body="user_id" type="string">
  The ZBD user ID of the player the session is for.
</ParamField>

<ParamField body="project_id" type="string">
  The project the session should be scoped to. Membership is checked against
  this player.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://api.zbdpay.com/api/v1/zbd-widget/sessions \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "b2c3d4e5-f6a7-4890-abcd-ef0123456789",
    "project_id": "1d2e3f40-5a6b-4c7d-8e9f-0a1b2c3d4e5f"
  }'
```
</RequestExample>

<ResponseExample>
```json 201
{
  "success": true,
  "message": "Session created successfully.",
  "data": {
    "session_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expires_at": "2026-05-27T19:04:05Z",
    "widget_url": "https://widget.zbdpay.com?session_token=eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9..."
  },
  "error": null
}
```
</ResponseExample>

`widget_url` is the hosted widget with the token already attached — hand it
straight to the client rather than assembling the URL yourself. For your own
API calls, pass the token as `Authorization: Bearer <session_token>`.

Mint a fresh session rather than trying to refresh: the lifetime is fixed at
four hours.

## Errors

| Status | Reason |
|---|---|
| `400` | Missing or malformed `user_id` |
| `401` | Missing or invalid API key |
| `403` | The player is not a member of the named project |
| `404` | No such user |
