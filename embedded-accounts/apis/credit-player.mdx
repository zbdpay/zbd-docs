<Info>
  **Requires activation.** Available once ZBD switches this feature on for your account. Until then it returns a 503 — that means the feature is off, not that the API is down. Ask your ZBD contact to enable it.
</Info>

Credit a player: `user_id`, `currency_code`, `amount`. Tag is always `Rewarded` and is not selectable. Response echoes `transaction_id`

<ParamField header="x-api-key" type="string" required>
  Your ZBD API key. Call this endpoint from your server only.
</ParamField>

<ParamField header="Idempotency-Key" type="string" required>
  A unique key per request so retries are not processed twice.
</ParamField>
