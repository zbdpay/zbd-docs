title: "Update a currency"
description: "Merge-patch name / icon_url / precision."
api: "PATCH https://api.zbdpay.com/api/v1/publishers/{publisherId}/virtual-currencies/{currencyCode}"
---

## Description

Updates a virtual currency. This is a merge-patch: send only the fields you
want to change and the rest are left alone.

`code` is **immutable after creation** and cannot be patched. To change a
currency's ticker you have to create a new currency.

<Warning>
  Changing `precision` on a currency players already hold a balance in changes
  how existing amounts are interpreted. Confirm the effect on outstanding
  balances before patching it in production.
</Warning>

## Configuration

### Header Parameters

<ParamField required header="x-api-key" type="string">
  Your ZBD publisher API key. Call this from your server only.
</ParamField>

### Path Parameters

<ParamField required path="publisherId" type="string">
  Your ZBD publisher ID.
</ParamField>

<ParamField required path="currencyCode" type="string">
  The currency ticker, for example `GOLD`.
</ParamField>

### Body

<ParamField body="name" type="string">
  Display name, up to 100 characters.
</ParamField>

<ParamField body="precision" type="integer">
  Number of decimal places the currency is denominated in.
</ParamField>

<ParamField body="icon_url" type="string">
  URL of an icon to display alongside the currency.
</ParamField>

<RequestExample>
```bash cURL
curl -X PATCH https://api.zbdpay.com/api/v1/publishers/{publisherId}/virtual-currencies/GOLD \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Gold Coins",
    "icon_url": "https://cdn.zbdpay.com/virtual-currencies/gold-v2.png"
  }'
```
</RequestExample>

## Errors

| Status | Reason |
|---|---|
| `400` | Attempted to patch `code`, or `name` exceeds 100 characters |
| `401` | Missing or invalid API key |
| `403` | The API key does not belong to `publisherId` |
| `404` | No such currency, or it has been soft-deleted |
