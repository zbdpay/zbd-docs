## Description

Creates a project. Projects partition an economy — a separate game, title or
environment under one publisher account — and currencies are linked to them
individually.

<Warning>
  The slug `name` is derived server-side from `display_name` and is **not
  accepted as input**. Sending it has no effect.
</Warning>

<Info>
  **Requires activation.** Available once ZBD switches this feature on for your
  account. Until then it returns a bare `503` — that means the feature is off,
  not that the API is down. Ask your ZBD contact to enable it.
</Info>

## Configuration

### Header Parameters

<ParamField required header="x-api-key" type="string">
  Your ZBD publisher API key. Call this from your server only.
</ParamField>

### Path Parameters

<ParamField required path="publisherId" type="string">
  Your ZBD publisher ID.
</ParamField>

### Body

<ParamField required body="display_name" type="string">
  Human-readable name for the project, up to 256 characters.
</ParamField>

<ParamField body="description" type="string">
  Optional description, up to 1000 characters.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://api.zbdpay.com/api/v1/publishers/{publisherId}/projects \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "display_name": "Fortnite Rewards",
    "description": "Virtual-currency rewards for the Fortnite integration."
  }'
```
</RequestExample>

<ResponseExample>
```json 201
{
  "success": true,
  "message": "Project created successfully.",
  "data": {
    "id": "1d2e3f40-5a6b-4c7d-8e9f-0a1b2c3d4e5f",
    "publisher_id": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
    "name": "fortnite-rewards",
    "display_name": "Fortnite Rewards",
    "description": "Virtual-currency rewards for the Fortnite integration.",
    "created_at": "2026-05-27T15:04:05Z",
    "updated_at": "2026-05-27T15:04:05Z",
    "virtual_currencies": []
  },
  "error": null
}
```
</ResponseExample>

`name` in the response is the server-derived slug. `virtual_currencies` is empty
until you [link a currency](/embedded-accounts/apis/link-currency).

## Errors

| Status | Reason |
|---|---|
| `400` | `display_name` missing or over 256 characters, or `description` over 1000 |
| `401` | Missing or invalid API key |
| `403` | The API key does not belong to `publisherId` |
| `503` | The Embedded Accounts feature is not switched on for your account |
