<Info>
  **Requires activation.** Available once ZBD switches this feature on for your account. Until then it returns a 503 — that means the feature is off, not that the API is down. Ask your ZBD contact to enable it.
</Info>

Create workspace. `display_name` required ≤ 256, `description` optional ≤ 1000. The slug `name` is derived server-side and is **not accepted as input**

<ParamField header="x-api-key" type="string" required>
  Your ZBD API key. Call this endpoint from your server only.
</ParamField>

<ParamField path="publisherId" type="string" required>
  Your ZBD publisher ID.
</ParamField>
