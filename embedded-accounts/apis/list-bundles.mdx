---

## Description

Returns the bundles defined for a currency. A bundle packages an amount of
virtual currency, and optionally digital assets, behind a single price.
Archived bundles are excluded.

<Warning>
  `currency_code` is a **required** query parameter. Calling the endpoint
  without it is a `400`, not an unfiltered list.
</Warning>

<Note>
  Bundles are readable only. There is no working purchase route on this surface
  — buying a bundle is not implemented yet.
</Note>

<Info>
  **Requires activation.** Available once ZBD switches this feature on for your
  account. Until then it returns a bare `503` — that means the feature is off,
  not that the API is down. Ask your ZBD contact to enable it.
</Info>

## Configuration

### Header Parameters

<ParamField required header="x-api-key" type="string">
  Your ZBD publisher API key. Call this from your server only.
</ParamField>

### Path Parameters

<ParamField required path="publisherId" type="string">
  Your ZBD publisher ID.
</ParamField>

### Query Parameters

<ParamField required query="currency_code" type="string">
  The currency ticker to list bundles for, for example `GOLD`.
</ParamField>

<ParamField query="skip" type="integer">
  Number of rows to skip.
</ParamField>

<ParamField query="take" type="integer">
  Number of rows to return.
</ParamField>

<RequestExample>
```bash cURL
curl "https://api.zbdpay.com/api/v1/publishers/{publisherId}/bundles?currency_code=GOLD" \
  -H "x-api-key: YOUR_API_KEY"
```
</RequestExample>

## Errors

| Status | Reason |
|---|---|
| `400` | `currency_code` not supplied |
| `401` | Missing or invalid API key |
| `403` | The API key does not belong to `publisherId` |
| `404` | No such publisher |
| `429` | Rate limit exceeded |
| `503` | The Embedded Accounts feature is not switched on for your account |
