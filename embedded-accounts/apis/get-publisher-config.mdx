---
title: "Get publisher config"
description: "Publisher's own cashout routing config."
api: "GET https://api.zbdpay.com/api/v1/publishers/{publisherId}/config"
---

## Description

Returns your publisher account's own configuration, including how cash outs are
routed. Read this rather than hard-coding assumptions about which rails are
available to you.

## Configuration

### Header Parameters

<ParamField required header="x-api-key" type="string">
  Your ZBD publisher API key. Call this from your server only.
</ParamField>

### Path Parameters

<ParamField required path="publisherId" type="string">
  Your ZBD publisher ID.
</ParamField>

<RequestExample>
```bash cURL
curl https://api.zbdpay.com/api/v1/publishers/{publisherId}/config \
  -H "x-api-key: YOUR_API_KEY"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "success": true,
  "message": "Publisher config retrieved successfully.",
  "data": {
    "publisher_id": "d82f6a14-3e97-4b50-8c2d-19f7a4e0b638",
    "cashout_routing_type": "EMBEDDED_PAYOUTS"
  },
  "error": null
}
```
</ResponseExample>

<Note>
  Cash out runs on [Embedded Payouts](/embedded-payouts). The live rails move
  USD points through that surface rather than a publisher's own virtual
  currency.
</Note>

## Errors

| Status | Reason |
|---|---|
| `401` | Missing or invalid API key |
| `403` | The API key does not belong to `publisherId` |
