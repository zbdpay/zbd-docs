---
title: "Get Earnings"
description: "Read the earnings ZBD tracks for a user."
api: "GET https://api.zbdpay.com/api/v1/users/{userId}/balances"
---

<Note>
  Only for programs where ZBD tracks earnings. If you track earnings yourself, this returns `403 feature_not_enabled`.
</Note>

Use this to show a user what they've earned in your own product.

## Configuration

### Header Parameters

<ParamField required header="x-api-key" type="string">
  Your ZBD API key.
</ParamField>

### Path Parameters

<ParamField required path="userId" type="string">
  The ZBD user ID returned by Create a User.
</ParamField>

<RequestExample>
```bash cURL
curl https://api.zbdpay.com/api/v1/users/4ac4fd8a-cc2c-4d03-af09-a76f4e89d652/balances \
  -H "x-api-key: YOUR_API_KEY"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "success": true,
  "message": "Balances retrieved.",
  "data": {
    "user_id": "4ac4fd8a-cc2c-4d03-af09-a76f4e89d652",
    "balances": [
      { "currency": "USD", "available": 5000 }
    ]
  },
  "error": null
}
```
</ResponseExample>

`available` is what the user can cash out now, in the currency's smallest unit.

## Errors

| HTTP | `code` | When |
| --- | --- | --- |
| `403` | `feature_not_enabled` | You track earnings yourself |
| `404` | `user_not_found` | The user doesn't exist under your key |
