---
title: "List Webhooks"
description: "List your webhook subscriptions."
api: "GET https://api.zbdpay.com/api/v1/webhooks/subscriptions"
---

## Configuration

### Header Parameters

<ParamField required header="x-api-key" type="string">
  Your ZBD API key.
</ParamField>

<RequestExample>
```bash cURL
curl https://api.zbdpay.com/api/v1/webhooks/subscriptions \
  -H "x-api-key: YOUR_API_KEY"
```
</RequestExample>

<ResponseExample>
