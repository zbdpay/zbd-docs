title: "Deplete Legacy User"

---

## Description

<Info>
  This is a Legacy Cashout Widget (type-4) server endpoint. It does not debit an
  EA workspace balance.
</Info>

Reverse an available fund by debiting publisher points from a widget user's
point balance and returning them to the project's configured sink/source
account. This creates a new debit; it does not modify the original fund
transfer. `amount` is an integer in the precision of the project's configured
point currency. For a two-decimal currency such as USDZ, `100` represents
`1.00`.

This endpoint is idempotent on `idempotency_key`. The user must already have enough point balance for the debit.

## Configuration

### Header Parameters

<ParamField required header="apikey" type="string">
  Your ZBD project API key (production scope).
</ParamField>

<ParamField initialValue="application/json" header="Content-Type" type="string">
  Content Type
</ParamField>

### Body Parameters

<ParamField required body="user_id" type="string">
  The ZBD user ID returned by Create User.
</ParamField>

<ParamField required body="amount" type="integer">
  Integer amount in the configured currency precision. For a two-decimal
  currency, `100` represents `1.00`.
</ParamField>

<ParamField required body="currency" type="string">
  Exact point currency code provisioned for the project. `USDZ` below is an
  example, not a global default.
</ParamField>

<ParamField required body="idempotency_key" type="string">
  Unique key to prevent duplicate transfers. Use a UUID.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://api.zbdpay.com/api/v1/widget/users/deplete \
  -H "apikey: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "4ac4fd8a-cc2c-4d03-af09-a76f4e89d652",
    "amount": 500,
    "currency": "USDZ",
    "idempotency_key": "551d1b1b-c387-4e16-9a7a-c15be30d0d62"
  }'
```
</RequestExample>
