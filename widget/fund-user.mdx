## Description

<Info>
  This is a Legacy Cashout Widget (type-4) server endpoint. EA publishers fund
  or reward users through their provisioned Embedded Accounts integration.
</Info>

Credit publisher points to a widget user's point balance. `amount` is an integer
in the precision of the project's configured point currency. For a two-decimal
currency such as USDZ, `100` represents `1.00`.

This endpoint is idempotent on `idempotency_key`.

## Reverse a fund

To take back points that you previously funded, call
[`POST /api/v1/widget/users/deplete`](/widget/deplete-user). This creates a new
debit from the user's currently available point balance back to your configured
sink/source account; it does not undo or mutate the original fund transfer.

Use a new `idempotency_key` for the deplete request. A deplete can only succeed
while the user has enough available points. It cannot recover points that have
already been spent or cashed out.

## Configuration

### Header Parameters

<ParamField required header="apikey" type="string">
  Your ZBD project API key (production scope).
</ParamField>

<ParamField initialValue="application/json" header="Content-Type" type="string">
  Content Type
</ParamField>

### Body Parameters

<ParamField required body="user_id" type="string">
  The ZBD user ID returned by Create User.
</ParamField>

<ParamField required body="amount" type="integer">
  Integer amount in the configured currency precision. For a two-decimal
  currency, `100` represents `1.00`.
</ParamField>

<ParamField required body="currency" type="string">
  Exact point currency code provisioned for the project. `USDZ` below is an
  example, not a global default.
</ParamField>

<ParamField required body="idempotency_key" type="string">
  Unique key to prevent duplicate transfers. Use a UUID.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://api.zbdpay.com/api/v1/widget/users/fund \
  -H "apikey: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "4ac4fd8a-cc2c-4d03-af09-a76f4e89d652",
    "amount": 1000,
    "currency": "USDZ",
    "idempotency_key": "90f9371e-c48a-4bc9-9075-ef7a4c6816ec"
  }'
```
</RequestExample>
