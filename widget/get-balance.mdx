title: "Get Legacy User Balance"

api: "GET https://api.zbdpay.com/api/v1/widget/users/{user_id}/balance"
---

## Description

<Info>
  This is a Legacy Cashout Widget (type-4) server endpoint. EA Widget balance
  and currency metadata come from the authenticated EA account summary.
</Info>

Returns the user's widget reward balance for your project. Use this from your server when you need to show a user's cashout-ready balance outside the widget.

Amounts are integer values in the project's configured currency precision. For
a two-decimal currency, `100` represents `1.00`. Use the returned currency code
and your provisioned currency configuration; do not assume every project uses
USD or two decimal places.

## Configuration

### Header Parameters

<ParamField required header="apikey" type="string">
  Your ZBD project API key (production scope).
</ParamField>

### Path Parameters

<ParamField required path="user_id" type="string">
  The ZBD user ID returned by Create User.
</ParamField>

<RequestExample>
```bash cURL
curl https://api.zbdpay.com/api/v1/widget/users/4ac4fd8a-cc2c-4d03-af09-a76f4e89d652/balance \
  -H "apikey: YOUR_API_KEY"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "userId": "4ac4fd8a-cc2c-4d03-af09-a76f4e89d652",
  "balances": [
    {
      "currency": "USD",
      "availableBalance": 5000,
      "totalBalance": 5000
    }
  ]
}
```
</ResponseExample>
